遊戲開啟說明
==============

請用資料夾入面嘅啟動檔開遊戲。
唔好直接雙擊 index.html。雙擊 HTML 檔 Chrome 開唔到呢個遊戲。


Windows
-------
1. 雙擊「開啟遊戲.bat」。
2. 會彈出一個黑色視窗，跟住瀏覽器會自動打開遊戲。
3. 玩嘅時候，唔好關閉嗰個黑色視窗。
4. 玩完要結束：喺黑色視窗按 Ctrl+C，然後關閉視窗。


Mac：Miss 上課前，每部 Mac 做一次
--------------------------------
呢步要喺玩遊戲嗰部 Mac 做。做完之後，學生雙擊就開到。
唔使安裝任何新程式。

1. 打開「終端機」。
2. 輸入 cd ，最後有一個空格。
3. 將成個遊戲資料夾拖入終端機，按 Enter。
4. 貼上下面呢行，再按 Enter：

    chmod +x "開啟遊戲.command" && xattr -dr com.apple.quarantine .

5. 雙擊「開啟遊戲.command」試一次。瀏覽器打開、終端機仍然開住，就裝好。


Mac：學生開遊戲
---------------
1. 雙擊「開啟遊戲.command」。
2. 會彈出「終端機」視窗，跟住瀏覽器會自動打開遊戲。
   如果部機有安裝 Google Chrome，會用 Chrome 打開。
3. 玩嘅時候，唔好關閉嗰個終端機視窗。
4. 玩完要結束：喺終端機按 Control+C，然後關閉視窗。


瀏覽器冇自動打開
----------------
睇黑色視窗或者終端機上面嗰行網址。
複製去 Chrome 的地址欄，然後按 Enter。
